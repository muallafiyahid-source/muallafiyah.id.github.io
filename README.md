# Website Muallafiah.id

Website statis gratis untuk bisnis jersey custom Muallafiah.id.

## File utama
- `index.html` — isi website
- `style.css` — tampilan
- `script.js` — menu, filter produk, animasi, dan formulir WhatsApp
- folder `assets` — seluruh gambar contoh

## Pengaturan wajib
Buka `script.js`, lalu ganti:

```js
const WHATSAPP_NUMBER = "6281234567890";
```

Gunakan format negara tanpa tanda `+`, contoh nomor 0812-3456-7890 menjadi `6281234567890`.

Buka `index.html`, lalu ganti:
- nomor WhatsApp
- username Instagram
- lokasi
- tautan Instagram, TikTok, dan Shopee
- testimoni dan informasi usaha

## Menjalankan
Klik dua kali `index.html`, atau unggah seluruh isi folder ke GitHub Pages.
